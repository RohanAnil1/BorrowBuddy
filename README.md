# BorrowBuddy

Campus-only peer-to-peer lending platform for verified Bennett University students. Replaces informal borrowing via WhatsApp groups with structured availability tracking, secure handovers, reputation, and dispute handling.

The Next.js web app and native Kotlin/Jetpack Compose Android app share the same Supabase backend. Campus features include Lost & Found, semester giveaways, collection receipts, handover scheduling, and offline recovery.
